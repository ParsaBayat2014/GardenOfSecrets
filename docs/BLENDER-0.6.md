# Blender 0.6 — production character adaptation

Raha now uses an explicitly credited adaptation of Ellie Pose Library v2.0.0, © Blender Studio, CC-BY. This is a third-party production asset, not an original sculpt by this project. The official publisher listing is https://www.blender.org/download/demo-files/#assets and the exact source bundle, checksum and byte count are recorded in art-source/vendor/SOURCE.json. Preserve app/src/main/assets/rebuild/licenses/Blender-Studio-Ellie.txt with any redistribution of the character, its renders, source or APK.

Changes: teal denim with the source bag palette retained, removal of source pins, earrings and wristwatch, a reshaped static ponytail, contiguous atlas UV regions, baked base color, normal and roughness maps, a fitted 23-joint game skeleton with merged source weights, and captured Blink/Speak/Smile poses. The source film rig, particle hair and its embedded scripts are not needed at runtime. The two other characters and the environment meshes retain their 0.5 designs; they have not been rebuilt to this new art standard.

Reproduce: download the official bundle with tools/fetch-studio-source.py, then run Blender 5 --background --factory-startup --disable-autoexec --python tools/blender/adapt-studio-character.py. The adapter reads the official .blend without executing its embedded scripts. Render the portable mobile master using tools/blender/render-studio-character.py. Output .blend files are in art-source/blender; packed textures are included in the mobile master and separate source PNGs are in art-source/textures/studio-raha. Use render-studio-garden.py to recreate the separate lighting showcase.

Verification covers nonzero bounded facial geometry deltas, compact skeleton, baked images, embedded source attribution, live face motion and walking, the complete 26-discovery chapter, three locks, independent saves and final epilogue. Android build, lint, exact packaged asset matching and signing are required before release. No physical phone test or Myket submission has been completed. Rendered portraits/showcases are Blender renders, not claims about mobile render quality, frame rate or commercial parity.
